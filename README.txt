غزل و محسن — دعوتنامه عروسی فارسی

فایل اصلی:
- index.html
- styles.css
- script.js
- assets/

برای شخصی‌سازی:
1) عکس اصلی را با فایل assets/hero-default.jpg جایگزین کنید.
2) در script.js بخش CONFIG را تغییر دهید:
   - whatsappNumber
   - whatsappMessage
   - googleMapsUrl
   - weddingDate
3) برای موسیقی، فایل assets/background-ambient.wav را با موسیقی دلخواه خود جایگزین کنید.
   نام فایل را ثابت نگه دارید یا src در index.html را تغییر دهید.

نکته:
مرورگرها معمولاً اجازه پخش خودکار صدا را بدون تعامل کاربر نمی‌دهند؛ بنابراین دکمه موسیقی در صفحه اصلی برای شروع صدا قرار داده شده است.
